A browser earns coverage only from a fresh health beacon. An installed-but-silent extension counts as stale, never as protected. "Nav blocks" reads the extension's own block engine: only an endpoint that says it read that engine can be called armed or not armed, so an endpoint that stayed silent reads "Not reported" rather than either verdict. "Guard health" is a different reading on a different rail: whether the in-page guard was inspecting sends at all. It is reported by the endpoint, never inferred here, so an endpoint that has never reported it reads "Not reported" and never "Healthy". The fleet tile counts those endpoints, so an unmeasured fleet cannot be read as a clean one.

AI GOVERNANCE OPT-OUTS

An endpoint can be authorized to stop DeVoid governing a runtime. While an opt-out is in force that runtime is not governed on that endpoint, and it is not repaired automatically. Where no readable opt-out transition has been reported, the row reads “Not reported”: that coverage has not been measured.

No endpoints are in scope, so there is no opt-out coverage to report. This is not a statement that any runtime is governed.
